How it works
  • Ride providers set route, departure time, vehicle type, seats, and fare
  • Ride seekers browse available rides and send booking requests
  • Providers can accept or reject requests
  • Payment is cash-based only and negotiated between riders
  • Both parties can cancel at any time with automatic notifications
